# Trattoria del Corso

**Ristorante tipico umbro a Foligno (PG)**

Nel cuore del centro storico di Foligno (PG), la Trattoria del Corso propone la vera
cucina tipica umbra con cottura lenta nel forno a legna, pasta fresca e i famosi
**5 Cocci** su Corso Cavour 54.

## Percorsi rapidi

- **Sito web:** [trattoriadelcorso.it](https://trattoriadelcorso.it/)
- **Posizione:** Corso Cavour, 54, 06032 Foligno (PG), Italia
- **Telefono:** +39 0742 97033
- **Orari:** Martedì chiuso · Lun–Dom 12:00–14:30 | 19:30–22:30

## Menu

Il menu combina tradizione e stagionalità:

- **Antipasti** — salumi umbri, formaggi locali, bruschette
- **Primi** — gnocchi al Sagrantino, pasta fresca fatta in casa
- **Secondi** — baccalà della Nonna, grigliata di agnello, parmigiana di melanzane
- **Contorni** — selezione di contorni stagionali
- **Dolci** — rocce di cocco, crostata, gelato artigianale
- **Vini** — produzioni locali dell'Umbria e selezioni italiane

## Tecnologia

Sito realizzato con:

- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS 4** per lo styling
- **PWA** con service worker per l'installazione sull'home screen
- **Leaflet** per la mappa interattiva

## Sviluppo locale

**Prerequisiti:** Node.js 20+

1. Installare le dipendenze:
   ```bash
   npm install
   ```
2. Avviare il server di sviluppo:
   ```bash
   npm run dev
   ```
3. Aprire [http://localhost:3000](http://localhost:3000) nel browser.

## Build di produzione

```bash
npm run build
```

I file generati vengono scritti nella cartella `dist/`.
